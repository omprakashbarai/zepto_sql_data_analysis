# zepto_sql_data_analysis
End-to-end SQL data analysis project on Zepto product inventory and pricing, including data cleaning, exploration, and business insights using PostgreSQL.

Zepto SQL Data Analysis Project

This project performs an end-to-end SQL-based analysis of Zepto’s product inventory dataset. The objective is to clean raw product data, analyze pricing and discount patterns, and extract actionable business insights related to inventory availability and revenue generation.

The dataset was imported from Excel (CSV format) into PostgreSQL, followed by structured data exploration, cleaning, and analytical querying.



 Key Objectives

Analyze product pricing, discounts, and inventory levels

Identify high-value and high-revenue products

Understand stock availability and category-wise performance

Apply real-world SQL queries for business decision-making



Tools & Technologies

PostgreSQL

SQL (DDL, DML, Aggregations, CASE, GROUP BY)

Excel / CSV


 Key Analysis Performed

Data cleaning and validation

Category-wise revenue estimation

Discount and pricing analysis

Inventory stock analysis

Product weight and value-based classification
